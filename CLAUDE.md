# Claude Code Rules — Riser Tech Dev

## Git Permissions

- **Never push to remote** (`git push`) without explicit user permission.
- **Never create new branches** (`git checkout -b` or `git branch`) without explicit user permission.
- After completing code changes, commit locally and ask: "Ready to push — shall I?"
- Wait for a clear "yes", "ok", "push it" or similar confirmation before any `git push` or branch creation.
